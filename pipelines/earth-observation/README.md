# Earth observation adapter

Presentation routes must consume preprocessed outputs, never invoke Google Earth Engine during a page request.

No Earth observation product is currently processed because no validated product manifest or existing GEE output was supplied. A product may be published only with a sidecar metadata file containing sensor, acquisition period, cloud filtering, native/output resolution, processing method, thresholds or classes, units, licence, limitations, and processing timestamp. Set `EO_MANIFEST_PATH` to a reviewed manifest generated by the offline workflow; credentials remain server-side and must not use a `NEXT_PUBLIC_` name.

Accepted browser delivery is a COG-backed tile endpoint or static image tiles. Raw rasters and service-account credentials must not be placed in `public/`.
